# Arx-Net
Open source graph visualization tool
This is the original arx-net version, developed without react, and the actively maintained branch.
The react version can be found in: https://github.com/Dwarakesh-V/arx-net/tree/main

Lead developer: Dwarakesh Venkatesh ([https://github.com/vdwarakesh](https://github.com/vdwarakesh)) <br>
Supporting developer: Shyam Sundar Raju ([https://github.com/shyamsundarraju](https://github.com/Shyam-Sundar-Raju)) <br><br>

Developed using D3.js for creation, manipulation and visualization, and utilities on graphs and trees.
